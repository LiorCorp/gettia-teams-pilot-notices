GettIA · pilote technique

Confidentialité

Mise à jour : 28 septembre 2026

Cette notice concerne uniquement l'assistant Teams de test exploité par GettIA pour un compte Microsoft 365 autorisé. Le pilote utilise des exemples fictifs. N'envoyez pas de factures réelles, de données personnelles inutiles, d'identifiants ni d'informations confidentielles.

Ce qui est traité

Pour limiter l'accès et répondre, le service traite l'identifiant du compte autorisé, les messages envoyés au bot, les réponses, les horodatages et des données techniques de conversation. Des journaux techniques peuvent contenir ces informations pour diagnostiquer les erreurs du pilote.

Parcours des messages

Les messages transitent par Microsoft Teams et Azure Bot dans l'environnement de l'organisation qui héberge le compte de test, puis par l'instance Hermes exploitée par GettIA sur son Mac mini. Leur contenu est envoyé à un service de modèle d'IA externe, actuellement configuré via Nous pour le modèle Upstage Solar Pro 4, afin de produire la réponse. La localisation exacte de ce traitement externe n'est pas établie pour ce pilote : c'est l'une des raisons pour lesquelles seules des données fictives doivent être utilisées.

L'assistant n'a aucun accès à Sage ou à Zeendoc et ne modifie aucun dossier. Il ne prend aucune décision métier.

Durée et contrôle

GettIA conserve les journaux locaux nécessaires au diagnostic pendant le pilote et les supprime à sa clôture. La copie des conversations dans Teams relève des règles de conservation de l'organisation qui fournit le compte Microsoft 365. Seul le compte de test autorisé peut obtenir une réponse du bot.

Ces pages sont hébergées sur GitHub Pages. GitHub peut enregistrer des données techniques de visite, notamment l'adresse IP, selon sa propre politique de confidentialité.
